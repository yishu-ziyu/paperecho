# 纸上的回声 · Paper Echo

整晚叫纸上的回声。你不先写心情，用手把一句送到世界上另一个人那里。对方只说自己的事，不安慰你。

未说出口的也值得回应。

## 一局怎么走

推进大多靠手：拉、拖、折、放。

1. 把卡片往下拉，进房间
2. 把靠近你的情绪拖近中心，写下今晚那句，带着走
3. 对角拉，折成飞机，送到窗边
4. 转地球，拉满再放
5. 人找到了，把飞机往下拉，落到桌上
6. 在桌上放一件自己的具体事。对方只说自己的夜。想停了，把今晚折回去
7. 回信往下拉是拆开；再往下，放进信柜
8. 从信柜抽出一张，开始新的一晚；或者再去找他

## 本地运行

```bash
npm install
cp .env.example .env   # 可选：填模型 key，夜里会去找一个也说过类似话的人
npm run dev
```

没有 key 或请求超时时，回退到本地故事卡，一局仍能完整走完。
