# 补纸 · 核心对话必须走大模型，拒绝硬编码

接着正在做的切片 3。不要另开 PR，不要碰 .env，不要 git commit。

## 要让人感到什么

他写下的一天、再见面第一句、桌上说的话，都是这个人自己说出来的，不是从几句写死的模板里抽的。

## 必须改

`writeDay`、`growAwayThing`、`continueGreeting`、`speakFromDays` 里那些固定句池（灯还搁着、我又一个人过了一天、今晚又改到很晚……）不能再当开口。补日子、再见面第一句、第二个人开口，都走现有的模型调用（和今晚对谈同一条路）。把日子本、上次的话、今晚情绪交给模型，收回他的一句。

单测里可以用假的模型回复，不要在产品路径上留句池当正文。

名字不要写死 Goss / Michael 当唯一的人。Michael 只许当「空名字时的兜底」，不能当剧本。

## 怎样算过

- 产品路径上，日子和开口的正文来自模型返回，不来自写死的数组随机抽
- 模型暂时没回来时，可以等或沿用上一句，不要换成另一句写死的安慰
- 切片 3 原来的：按人分本、能找旧人、能遇新人，仍要成立

## 怎样算不过

- 再留一组中文模板当「他的一天」
- 硬编码人名当角色
- 两人自动见面、屋子、提交、.env

交活时写：日子和开口现在从哪调用模型；句池删了没有；单测怎么假模型。
