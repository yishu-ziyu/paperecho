# 折纸这一步：怎么抓住注意力

> 调研，未改代码。对的是 `FoldPhase`：对角拉两次，再把飞机送到窗。  
> 口味未拍板，不实现。

X 插件未登录，Mobbin 要付费。对照的是公开文章、GitHub 和获奖作品。

---

## 现在为什么抓不住

玩家刚写下今晚那句，下一秒看到的是一张平纸、一颗 16px 红点和三段说明。「再折一刀，成飞机 / 往对角拉 / 没有按钮。」手不知道捏哪里，纸也不像在折。

代码里这一步是：整张纸跟着拉力歪一点（`rotate` + `skew`），过 0.42 松手，`clipPath` 切一刀。没有翻起来的角，字也不会被折进去。第二次折和第一次长得几乎一样。注意力被导读卡吸走，物体本身是静的。

这和本关自己写的 Continuum 也对不上：手应该一直拿着同一张纸，纸自己变成飞机。

## 三条原则（翻成我们的话）

1. **用纸教，不用字教。** 空闲时角上自己呼吸，一只浅色手指从角拉到对角，循环。Guide 缩成一句，或干脆拿掉。Rauno：系统只教一次上滑。
2. **第一折把今晚那句藏进去。** Brother 把这一折当整晚最重要的画面。字被折痕吃掉，玩家才觉得「我封上了」，不是「我切了一下矩形」。
3. **角跟手，纸跟角。** 现在是整张纸 skew。应该是右上角那一瓣跟着手指翻过来，过线松手「啪」地折住。拉不够就弹回去。Emil：带着速度弹，不要瞬间归零。

## 建议怎么改（仍是纸飞机，不是 Arcade）

这一晚很静。抓住注意力靠「纸是活的」，不靠粒子和闪白。

**先做，立刻看得见**

- 角变大、会呼吸。Brother 用闪的记号；我们用珊瑚点慢慢胀缩，闲着也在叫人捏。
- 浅色手指幽灵：从右上角拉到左下，折住，再重来。手一按就停。
- 第一折：翻起来的三角盖住字。翻开的那面是纸背（略深一点），折痕一条软影子。松手过线，角拍下去，字只露出没被盖住的部分。
- 过线那一下：现有的短震 + 折纸声留下，再加角拍实的弹簧。不要再只靠「松开，折住」这五个字。

**再做，飞机才像折出来的**

- 两折长得不一样。第一折封信（藏字），第二折收成飞机鼻子/翅膀。现在两次都是同一条对角。
- 手指按在角上时，角或折痕露在手指上方一点（Rauno 的放大镜原则），免得自己挡住自己。
- 闲着时纸轻轻起伏一下。Brother 折之前纸会「ふにゃっ」软一下，告诉你这张能捏。

**不要做**

- 再加一段说明。
- 彩带、全屏闪、连续震动。
- 上 WebGL 真折纸。Brother 是十几人做的；我们要的是「字被折进去」和「角跟手」，不是鹤。

## 和现有代码怎么接

`FoldPhase` 已经有：拉力 `v`、阈值 0.42、过线震动、不够就 `spring.snap` 回去、`layoutId` 同一张纸。不用换手势，不用加按钮。

要换的是「纸怎么跟着 `v` 长」：从整张 `skew`，改成一角 `clip-path` + 纸背三角 + 字被盖住。幽灵手指是 idle 时的一层，按下就卸。

`prefers-reduced-motion`：幽灵手只闪一下角，不循环拉；折仍可点角两次（和现在的阈值提交并行）。
